# AllClean — landing page

Landing page de démonstration pour AllClean, un projet d'application de services à domicile : lavage de voiture, nettoyage de tapis et de couvertures, ménage. Le client décrit son besoin, les prestataires proposent leur prix et le client accepte l'offre qu'il préfère. Les prestataires, prix et notes affichés sont fictifs.

**Démo en ligne :** (lien GitHub Pages à ajouter ici)

## Contenu

- Démonstration interactive : choix du service, offres des prestataires, acceptation d'une offre
- Présentation des étapes et des services
- Section pour les prestataires
- Formulaire d'inscription à la liste d'attente avec contrôle de l'adresse e-mail
- Design adaptatif : ordinateur, tablette et mobile

## Technologies

HTML, CSS et JavaScript, sans framework. Un seul fichier : `index.html`.

## Lancer en local

Ouvrir `index.html` dans un navigateur.
